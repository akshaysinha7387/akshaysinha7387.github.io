Model routing decision
Gemini → Qwen
−99%
Marginal inference cost, same output bar

The saving came from changing how inference is paid for: off per-token vendor billing, onto a self-hosted open-weights model running on compute the team already operates.

How the economics change
  • Before. Vendor API rates on every input and output token, so cost scaled directly with usage.
  • After. Inference runs in-house, so the unit of cost becomes internal compute instead of per-token billing.
  • Quantization. FP8 cuts the model's memory footprint against higher-precision inference, which improves serving efficiency.
  • What the number excludes. −99% is marginal cost. Fully allocated cost still carries GPU depreciation, electricity, cooling and infrastructure overhead, and I would not claim those away.
